## 📋 About

A modern, responsive landing page for "Dekoor" furniture brand. Built as a portfolio project to demonstrate front-end development skills - clean UI, interactive components, and performance optimization.

## ✨ Features

- **Hero Section** - Full-screen with scalable background image and overlay content
- **Gallery Accordion** - Interactive image gallery with hover/click expand effect (CSS Flex + jQuery)
- **Best Seller Slider** - Product cards with prev/next navigation and active state animation
- **Category Accordion** - Furniture categories with expandable descriptions (click to toggle)
- **Mobile Menu** - Smooth hamburger navigation with animated dropdown
- **Partners Section** - Brand logo showcase with hover effects
- **Subscribe Form** - Newsletter signup with animated feedback
- **Fully Responsive** - Optimized for desktop, tablet, and mobile

## 🛠️ Tech Stack

| Technology | Purpose |
|-----------|---------|
| **HTML5** | Page structure & semantics |
| **CSS3** | Styling, Flexbox, responsive layout, transitions |
| **jQuery** | Interactivity (slider, accordion, menu toggle, dropdown) |
| **Font Awesome** | UI icons |
| **Google Fonts (Inter)** | Typography |

## 🚀 Performance Optimization

This project is optimized for fast loading:

- **Image compression** - All images compressed (hero background: 13MB → 76KB, **99% reduction**)
- **PNG → WebP conversion** - Modern format with significantly smaller file sizes
- **Lazy loading** - Below-fold images use the `loading="lazy"` attribute
- **External CDN** - jQuery, Font Awesome, and Google Fonts loaded via CDN

## 📱 Responsive Breakpoints

- **Desktop (>768px)** - Full layout with horizontal navigation
- **Mobile (≤768px)** - Hamburger menu, stacked content, adaptive text sizing

## 🧑‍💻 How to Run

1. Clone the repository
2. Open `index.html` in your browser

No build step or dependencies required - it's a pure static site.
